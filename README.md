# Drop Zone Squad

을지로를 배경으로 세 대원을 지휘하는 도트 생존 게임입니다.

시작 메뉴 왼쪽의 **생활관**에서 다섯 직업 중 세 명을 편성합니다. 뒤쪽 대원을 누르면 앞으로 나와 장비를 편집할 수 있고, **선두 지정**으로 출발 순서를 결정합니다. **크루 변경**에서 대원을 바꾸고 **저장**하면 편성과 장비를 기기에 보관합니다. 전투는 메인 화면 중앙의 **플레이**로 시작합니다.

세로형 개발 브랜치는 **개발자 모드**로 시작합니다. C~S 장비를 착용할 수 있으며 새 프로필은 테스트용 다이아 3,000개와 강화 가능한 기본 장비를 모델별로 12개씩 받습니다. **보급 상자**에서 일반 모드로 전환할 수 있습니다. 편성·보관함·다이아와 진행 중인 작전은 프로필마다 따로 저장됩니다.

일반 모드의 초기 다이아는 0개입니다. 벌크는 오른손 권총과 왼손 방패, 레이븐은 듀얼 SMG, 링스는 저격소총, 해머는 로켓포, CCT는 돌격소총으로 시작합니다. 전용 무기와 방패의 시작 등급은 C입니다. 생활관에서 무기를 누르면 1발 피해, 탄창, 재장전 시간을 확인할 수 있습니다. 교대해도 각 대원의 남은 탄약과 재장전 진행이 유지됩니다.

**보급 상자**는 다이아 100개로 열며, 직업 전용 무기 1개와 방패 또는 공용 방어구 1개를 무작위로 지급합니다. 같은 장비도 다시 나옵니다. 일반 적 처치는 다이아 1개, 보스 처치는 5개입니다. 무기는 첫 두 상자에서 C, 세 번째에서 B, 매 20번째에서 A가 확정됩니다. 4~19번째는 B 30%, C 70%입니다. 첫 A 보장 이후 일반 개봉의 무기 확률은 A 8%, B 30%, C 62%입니다.

| 공용 장비 | C | B | A | S | S+ |
|---|---:|---:|---:|---:|---:|
| 헬멧 · 치명타 확률 | 3% | 6% | 10% | 15% | 22% |
| 장갑 · 재장전 속도 | +5% | +10% | +16% | +24% | +35% |
| 상의 · 최대 체력 | +8 | +16 | +28 | +45 | +65 |
| 하의 · 회피 확률 | 2% | 4% | 7% | 10% | 15% |
| 신발 · 이동 속도 | +3% | +6% | +10% | +15% | +22% |

치명타는 피해의 1.5배를 주고, 회피하면 해당 공격의 피해를 받지 않습니다. 생활관에서 표시하는 재장전 시간에는 장갑 효과가 포함됩니다. 상자에서는 C~S 장비가 나오며 S+는 합성으로 획득합니다. C등급 상의는 민간 조끼이며, 4구 야투경은 S+ 헬멧에 달려 있습니다.

생활관에는 장착한 전체 장비의 평균 아이템 레벨과 다음 대원 등급에 필요한 게이지가 표시됩니다. C·B·A·S·S+ 장비의 기본 아이템 레벨은 각각 10·20·30·40·50이며 강화 한 단계마다 1씩 오릅니다. 다음 등급 이상 장비를 서로 다른 슬롯에 세 개 장착하면 대원 머리 위의 **영구 돌파** 버튼으로 한 등급 승급할 수 있습니다. 장비를 교체해도 대원 등급은 유지됩니다. 레이븐의 복장과 초상화는 돌파 등급에 맞춰 바뀌며, 얼굴과 동작의 크기는 모든 등급에서 같습니다.

생활관의 **강화 단계**에서는 같은 모델·등급·강화 단계의 장비 두 개를 합성합니다. B·A 무기는 +5 두 개로 다음 등급이 되며, 모든 S 무기·방패·방어구는 +3 두 개로 S+ 한 개가 됩니다. 기존에 보유한 S +4·+5 무기도 같은 단계끼리 한 쌍으로 합성할 수 있습니다. 기본 피해 배율은 C 1배, B 1.6배, A 2.5배, S 5.5배, S+ 12배입니다. A는 강화 한 단계마다 C 기준 0.35배, S는 0.8배씩 더해집니다.

특수 스킬은 **출격할 때 장착한 전용 무기 등급**으로 결정됩니다. C와 B는 잠금, A와 S는 기본 특수 스킬, S+는 각성 특수 스킬을 사용합니다. 같은 무기 등급 안에서는 강화 후에도 같은 스킬을 유지하며, 벌크는 권총 등급을 기준으로 합니다. 전투 중에는 해당 대원을 선두로 교대해 수동으로 발동합니다.

| 대원 | A·S 무기 | S+ 무기 |
|---|---|---|
| 벌크 | 분대와 지원병이 들어가는 고정 벙커 | 8초 동안 이동하는 미니건 메카에 탑승합니다. 탑승 중에는 선두 교대가 잠깁니다. |
| 레이븐 | 쌍기관단총으로 3초간 난사합니다. | 난사를 최대 3회 충전합니다. 소모한 충전은 전투 시간 10초마다 하나씩 돌아옵니다. |
| 링스 | 일직선의 적을 꿰뚫는 관통 사격 | 보스를 우선 조준해 충전한 집중 레일건을 발사합니다. |
| 해머 | 포신을 세우고 박격포를 연속 발사합니다. | 다연장 공성포로 여러 지점에 로켓을 일제 발사합니다. |
| CCT | 코브라가 7초 동안 선회하며 지원 사격합니다. | A-10이 11초 동안 더 넓게 선회하며 연속 사격합니다. 두 형태 모두 대원을 교대한 후에도 유지됩니다. |

레벨업 때는 출전한 세 대원의 무기 강화와 분대 공용 증강에서 카드 세 장이 제시됩니다. 한 대원의 무기는 해당 작전에서 최대 3회 강화할 수 있고, 한 번에 기본 공격 피해가 20%씩 오릅니다.

분대 화력 증강은 총 +10%, +20%, +30%의 세 단계입니다. 응급 처치는 생존한 분대원과 지원병의 최대 체력 50%를 회복하고, 추가 체력은 작전 시작 최대 체력의 30%씩 올립니다. 자석은 같은 층에서 시야가 닿는 30m 안의 경험치 조각을 즉시 수집하며 10초 동안 수집 범위를 유지합니다.

일시 정지 또는 증강 화면의 **저장 후 나가기**로 작전을 중단할 수 있습니다. 메인 화면의 **이어하기**를 누르면 전투 시간, 탄약·체력, 증강 후보, 지원병과 전개 중인 스킬까지 복원됩니다. 진행 중에는 기기에 자동 저장합니다. 승리·전멸하면 해당 작전의 이어하기가 종료됩니다.

벌크가 벙커를 전개하면 스킬 버튼에 **벙커 해제**와 남은 내구도가 표시됩니다. 버튼을 다시 누르면 분대가 하차하고 10초 후 재전개할 수 있습니다. 내구도가 0이 되면 벙커가 폭발해 주변 적을 밀어내며, 파괴된 순간부터 15초 후 재전개할 수 있습니다.

각 스테이지의 세 웨이브는 마지막 8초에 한 방향에서 대규모 무리가 들어옵니다. 세 번째 웨이브가 끝나면 보스를 처치해야 다음 스테이지로 넘어갑니다. 대원 체력, 경험치와 증강은 이어지며 세 번째 보스를 처치하면 작전을 완료합니다.

| 스테이지 | 전투 구성 | 보스 패턴 |
|---|---|---|
| 을지로 봉쇄선 | 기본형, 빅웨이브 생성 목표 10·14·18마리 | 철갑 돌격대장이 예고한 직선을 따라 돌진 |
| 환승로 범람 | 물량 중심, 20·26·32마리와 빠른 적 비중 증가 | 공진 파쇄기에서 바깥쪽으로 원형 충격파가 퍼짐 |
| 종점 포격지대 | 보스 중심, 12·15·18마리와 중장갑 적 | 종점 포격지휘관이 선두 위치를 세 번 조준한 뒤 순차 포격 |

1·3스테이지에서는 보스 등장 전에 마지막 웨이브의 잔당이 물러납니다. 2스테이지에서는 잔당이 보스와 함께 싸웁니다. 종점 포격지휘관의 체력은 1,200입니다.

웨이브 간격, 적 조합과 보스 체력은 `game/stages.js`, 보스 공격의 예고 시간·범위·피해는 `game/bosses.js`, 무기의 기본 피해와 관통 배율은 `game/combat.js`, 등급·강화·탄창·재장전·상자는 `game/equipment.js`에서 조정합니다. 스폰은 도달 가능한 위치와 스테이지의 적 수 상한을 따릅니다.

## 실행

PC에서는 `game/index.html`을 Chrome 또는 Edge에서 엽니다. WASD 또는 방향키로 이동하고 1–3으로 출전 순서에 따라 선두를 교대하며 Space로 스킬을 사용합니다. 휴대폰에서는 세로 화면에서 드래그로 이동하고 대원 버튼으로 교대하며 스킬 버튼으로 발동합니다. 지하철 출입구에서는 계단을 따라 걸어서 지상과 지하를 오갑니다.

## 구성

- `game/`에 게임 로직, Canvas 렌더러, UI, 폰트와 이미지가 있습니다.
- `android/`에 오프라인 WebView 앱과 적응형·원형·테마 아이콘이 있습니다.
- `work/`에 빌드, 에셋 가공, 브라우저 검증 스크립트가 있습니다.

## iPhone 빌드

Mac에서 `ios/DropZone.xcodeproj`를 열고 DropZone 대상의 Signing & Capabilities에서 개발 팀을 지정합니다. 연결한 iPhone을 선택하고 Run을 실행합니다. 앱은 저장소의 `game/` 폴더를 번들에 포함해 오프라인으로 실행합니다.

## Android 빌드

Windows PowerShell에서 프로젝트 루트를 기준으로 실행합니다. 빌드 스크립트는 Unity Hub의 기본 설치 경로에 있는 Android Build Support의 OpenJDK와 Android SDK를 사용합니다. SDK Platform 36과 Build Tools 36.0.0이 필요합니다. 최소 지원 버전은 Android 8입니다.

```powershell
.\work\build.ps1
.\work\package-usb.ps1
```

APK와 USB 설치 패키지는 `dist/`에 생성됩니다. 첫 빌드에서 로컬 테스트 서명 키를 생성합니다. 이미 설치한 앱에 업데이트하려면 이전 빌드의 `work/android-build/test.jks`를 같은 위치에 보관해야 합니다. 서명 키와 빌드 결과는 Git에서 제외됩니다.

## 검증

Node.js, Playwright와 기본 경로에 설치한 Chrome을 사용합니다.

```powershell
node work/test.cjs
node work/check-lineup.cjs
node work/check-zombie-stages.cjs
node work/touch.cjs
node work/check-tag-combat.cjs
node work/check-continue.cjs
node work/check-squad-skills.cjs
node work/check-squad-skill-ui.cjs
node work/check-stair-links.cjs
node work/review-shots.cjs
```

진행·증강·승패·재시작과 터치 이동 중 선두 교대를 확인합니다. 에셋 가공 스크립트에는 Python, Pillow가 필요하며 도로 생성에는 NumPy도 사용합니다. 게임 실행과 APK 빌드에는 가공이 완료된 `game/`의 에셋을 그대로 사용합니다.

Galmuri 폰트의 라이선스는 `game/Galmuri-LICENSE.txt`에 있습니다.

## 전투 작업실

```powershell
node design/combat-lab/server.cjs
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 세로형 실게임 화면에서 선두와 표적 배치를 선택한 뒤 기본 공격이나 스킬을 재생할 수 있습니다. 일시 정지, 프레임 이동, 속도 변경과 추가 이펙트별 비교를 지원합니다. `game/` 또는 `design/combat-lab/`을 저장하면 현재 설정으로 장면을 다시 엽니다.

이펙트 시안은 `design/combat-lab/fixture.js`에 있습니다. 작업실 서버가 미리보기에서만 이 스크립트를 불러옵니다.
